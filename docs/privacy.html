Privacy policy

Policy date: 4 October 2026

This policy describes CleanIQ's reviewed desktop source behavior, local records and the external tools it invokes. It does not promise zero network activity.

Telemetry and uploads

No built-in telemetry, analytics, crash uploader or automatic log upload was found in the reviewed packaged application source. This is a source-review finding, not a measurement of every runtime connection. Having no account does not establish that no data is collected.

Local operation history

CleanIQ writes JSON operation records to %LOCALAPPDATA%\PC Cleaner Tester\operation_logs\<operation_id>.json, with a fallback under your home folder at AppData\Local\PC Cleaner Tester\operation_logs. The older storage name is retained for history continuity. Windows package storage rules may affect the effective location.

Records can contain operation IDs, types, timestamps, outcomes, actions, exact file and registry paths, sizes, commands, and details including subprocess output and errors. These records are not automatically redacted or encrypted by CleanIQ.

History persists across exit and reopen. No automatic expiry, count limit or history-delete interface was found. You can manually delete history files when CleanIQ is closed if you no longer need them; this removes those records, not the effects of an operation. Update and uninstall retention have not been established. Interrupted saves may leave temporary .tmp files.

Diagnostics and settings

Operation monitor text is held in the interface's memory and may include personal paths. Selected worker and callback tracebacks redact the current home path and username; this does not cover all output or saved history. No persistent application preferences store or application crash-log file was found. Windows crash reporting is separate and depends on your system configuration.

Exports, backups and temporary files

You choose where to save process and service CSV exports. Process rows can include paths, command lines and network addresses. Exports have no automatic expiry. A network or cloud-synced destination may move these files off your device.

WSL disk compaction creates and retains a full VHDX backup at a location you choose. It can contain the distribution's files and other sensitive contents; incomplete backups may remain after failure. Manage these copies yourself, retaining needed recovery backups. DiskPart scripts in system temporary storage include the VHDX path; deletion is attempted afterward but can fail.

External tools and network activity

CleanIQ invokes tools whose behavior is separate from its own logging. WinGet listing accepts source agreements, and uninstall actions invoke the selected source or package uninstaller. Their source connections, logs and telemetry depend on the installed tools and configuration.

Microsoft Defender signature updates and scans may use Microsoft update, cloud protection or sample-submission services according to Defender settings and policy. Docker inspection and cleanup use the configured daemon and context, which may point to a remote machine; Docker Desktop or tool telemetry is separate.

Other invoked Windows tools include PowerShell/CIM, WSL, DiskPart, scheduled-task and process queries, volume optimization, System Restore, Disk Cleanup, Task Manager, Explorer and Settings. Their data handling and Windows diagnostics follow their own configuration. External endpoints, upload contents and retention were not established by this source review.

Support email and sharing logs

Contact marioszone01@gmail.com. Support emails contain whatever you choose to send, including your email address, message and any attachments. Email providers process those messages under their own policies. No fixed support-email deletion schedule is established here.

Before sharing logs or screenshots, redact personal paths, usernames, command-line secrets, network addresses and other private details. Share only the relevant excerpt; avoid sending entire operation-history folders or WSL backups. CleanIQ does not automatically send support messages or logs.

This website

These static pages include no analytics, external fonts or upload forms. If hosted on GitHub Pages, hosting requests and associated connection data are handled by GitHub under its own policies.
